# fake-door-export

Static marketing landing page for **LoboDoc**, used to validate demand for an AI-assisted export document workflow.

The page is aimed at small exporters, with a food-export positioning: helping teams organize export paperwork, country-specific requirements, and buyer request formats in one flow. Visitors can preview the concept and join a waitlist for beta access.

This repository is a prototype for product-idea validation, not a production application.

## Live site

[https://Lobo2u.github.io/fake-door-export/](https://Lobo2u.github.io/fake-door-export/)

## Run locally

Open `index.html` in a browser, or serve the directory:

```bash
# Python 3
python3 -m http.server 8080
```

Then visit `http://localhost:8080`.

## Tech

Single static page: HTML, CSS, and JavaScript in `index.html`. No build step or backend in this repo.

## Status

Prototype. Demand validation is in progress.
